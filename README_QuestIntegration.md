# Steps for Quest Support Integration

This file documents the steps required for Meta Quest support.

1. Download and install Meta XR Core SDK package (v71) 
- https://developers.meta.com/horizon/downloads/package/meta-xr-core-sdk

2. Place it in ExternalDependencies folder, e.g.:
```ExternalDependencies\MetaXRSDK\com.meta.xr.sdk.core-71.0.0.tgz```

Other Packages can be found at:
- https://developers.meta.com/horizon/downloads/package/meta-xr-sdk-all-in-one-upm
